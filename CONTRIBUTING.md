# Contributing

Issues and pull requests are welcome.

When reporting a problem, include:

- WSL version and networking mode (NAT or mirrored).
- Linux distribution and shell (for example, Kali with Zsh).
- Proxy software and listener type (HTTP, SOCKS5, or Mixed).
- Relevant command output, with credentials, subscription URLs, access tokens, and sensitive network details redacted.

Keep the project dependency-light and preserve compatibility with both Bash and Zsh. Please test shell syntax before submitting changes.

Do not commit personal Mihomo configurations, proxy-node credentials, subscription URLs, tokens, or private machine details.
